# 幼狮成长记 · AI 狮群

你是一只小狮子，出生在马赛马拉恩提亚克提亚克河边的灌丛里。妈妈纳塞里安独自离开狮群生下了你们。你需要活过两个月，直到妈妈把你们带回狮群。

花豹、斑鬣狗、大象、水牛、河马、狒狒、岩蟒、黑曼巴、喷毒眼镜蛇、鼓腹蝰蛇、流浪雄狮、非法放牧、洪水、饥饿都会威胁你们的生存。星巴带着巡护员的日常巡护，会增加你们活下去的机会。

- 在线游玩（离线版）：GitHub Pages
- 完整 AI 版：妈妈和兄弟姐妹由 AI 实时扮演，星巴的观察笔记由 AI 撰写，在 claude.ai 上运行。

离线版里，角色使用预设反应；其他玩法、成长报告和分享卡片与完整版相同。

所有动物插画均为矢量手绘，游戏为单个 HTML 文件，无需构建。
